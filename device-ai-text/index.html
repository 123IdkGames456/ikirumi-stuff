Local model connections

Quick setup

1 · Download your chat AI

Choose a small model. The download is saved by Ollama on your PC, not inside the website.

Ollama must be installed and running first.

Model downloads can be hundreds of MB to a few GB. Keep this page open until the download finishes.

2 · Download your image AI

Install Stable Diffusion WebUI Forge, then download an image checkpoint file (.safetensors) from a trusted model source. A basic model page is Stable Diffusion 1.5 on Hugging Face. Check the model's license and file size before downloading.

Put the checkpoint in Forge's models/Stable-diffusion folder, restart or refresh the model list, and keep Forge running. Image checkpoints are often several GB; this website cannot safely install them directly into Forge's folders.

3. Keep Ollama and Forge running. Configure their local API/CORS access for this page's origin. GitHub Pages may need local-server CORS settings; serving the page from localhost is often easier.

This page now requests chat-model downloads through Ollama. Models run on your PC; the website itself does not contain the model files. No sign-in or paid cloud API is required.

Your chats and saved images are stored in this browser's IndexedDB. Clearing browser site data may remove them; use Export backup regularly.
