Build your Blueprint

Connect logic visually. You do not need to read or write code.

1
Start with an event

Drag when game starts or every frame onto the grid.

2
Connect actions

Drop an action onto another action to snap it into the flow. Use the open notch under an event or control node to add steps.

3
Fill input pins

Change inline values directly, or drag a rounded value node into a matching socket. Green/blue value nodes provide data to an input.

4
Use control nodes

if, repeat, and forever contain a body area. Drop actions inside it.

5
Export to Unity

Use Export Unity Script when you want to turn your Blueprint into a C# script.

Tip: right-click a node to duplicate, detach, or delete it. Save downloads your Blueprint project file.
