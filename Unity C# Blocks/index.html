Build Unity scripts with blocks
This tool turns visual blocks into a real C# script you can copy into Unity. It works locally in your browser and does not need an AI service.
  1. Choose your script type and class name in the top settings of the code panel. These are not blocks.
  2. Search the library and click a block to add it, or drag blocks into the workspace.
  3. Set values on each block. Drag workspace blocks to reorder; use × to remove.
  4. Copy the generated C# into a matching .cs file in Unity. Editor-only scripts belong in an Editor folder.
Unity has a huge API surface, so the library includes common gameplay, rendering, physics, UI, input, animation, audio, networking, editor and advanced C# patterns. Some APIs depend on your Unity version or installed packages.
