Connect an AI model

This GitHub Pages app is the front-end. For real text-to-3D generation, connect a secure server endpoint that calls a provider such as a text-to-3D model API. Your server keeps the provider secret key private.

Security: Do not put a provider API key in this page or in a public GitHub repository. Use a server-side proxy and configure its URL in API setup.
