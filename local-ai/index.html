Privacy, limitations & setup

Understand what is local and what this website can do.

What stays local?

Chat history, instruction settings, and memory notes are saved in this browser's local storage. When you send a message, the prompt and recent chat history are sent to the server URL you configured. If that URL points to Ollama on your own computer, inference can happen locally.

First-time setup

1. Install Ollama from ollama.com on the computer running the browser.

2. Start Ollama, return here, open Connection & models, and test the connection.

3. Download a model and select it in Chat.

4. After the model is installed, you can chat offline as long as the local runtime is running.

Restrictions

Some open models are less restrictive than others, but none is guaranteed to answer absolutely everything. Model behaviour depends on its training, licence, configuration, and capabilities.

Security

Do not expose Ollama's API publicly. Avoid entering sensitive information into models you do not trust. Clearing browser site data can erase saved chats and settings; use Export to back up your conversations.

Local AI is a browser interface for a local runtime, not an AI model by itself.
