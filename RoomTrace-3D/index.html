Build a real 3D reconstruction

This uses WebSfM, a browser-based photogrammetry workspace. It can match overlapping photos, estimate camera poses, build point clouds and create mesh surfaces. Processing runs on your device.

How to use your capture:
1. Download your video or photo ZIP from the Capture tab.
2. Open WebSfM below.
3. Create a project and import the video or extracted photos.
4. Run the alignment / reconstruction workflow, then build a mesh and export it as GLB, glTF, OBJ or PLY when available.
5. Return here and load the exported model in the 3D viewer.

WebSfM is a separate open-source project. It is in beta, and dense reconstruction can take time or use a lot of memory on phones. A computer may work better for large scans.
