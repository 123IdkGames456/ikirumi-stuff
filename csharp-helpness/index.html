C# quick guide

Short explanations of common C# concepts.

Variables and typesint stores whole numbers, float stores decimal values, string stores text, and bool stores true or false.
int health = 100;\nfloat speed = 4.5f;\nstring playerName = "Player";\nbool isAlive = true;
MethodsA method groups instructions you can run when needed.
void Jump()\n{\n Debug.Log("Jump!");\n}
Conditionsif runs code only when a condition is true.
if (health <= 0)\n{\n Debug.Log("Player defeated");\n}
Lists and arraysArrays have a fixed size; List can grow or shrink.
using System.Collections.Generic;\nList names = new List();\nnames.Add("Alex");
Unity lifecycleAwake/Start usually initialize things; Update runs every frame; OnTriggerEnter needs a Collider setup and appropriate physics settings.
