Privacy and limitations

This is a browser-based learning environment. Code Lab can parse common public fields and simulate basic Debug.Log output, but it does not compile or run the full Unity engine. Messages sent to Gemini are processed by Google's API.

For a public website, a backend proxy is safer than sending a personal API key directly from the browser.
