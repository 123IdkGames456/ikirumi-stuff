IKIRUMI STUFF

This repository contains the Ikirumi Stuff hub itself.

The hub launcher lives in the root:
- index.html
- app.js
- styles.css
- sites.json

The sites.json registry is intentionally empty when there are no projects:
{
  "version": 10,
  "files": [],
  "sites": []
}

Text and HTML are standalone hub tools, not project sites. They must not be discovered or displayed as site cards.

When a new project is added later, place it in its own folder. GitHub mode discovers folders containing HTML pages, including pages that are not named index.html. If a folder has index.html, that page is preferred. Otherwise the first HTML page is used.

Project folders are separate from the root hub files. Do not put standalone Text or HTML tools inside the project-site collection.
